# 换刃之后的一秒钟

从 458 段单板滑行视频的 921 个完整弯出发，在原片旁旋转同一时刻的人体网格，观察靴、膝、骨盆和肩部怎样移动。[打开交互文章](https://tardisbooo.github.io/snowboard-analysis/)

文章包含十段同步回放、一个后刃弯的四相位 SMPL-H 表面与骨架，以及两套单目模型在 114 段视频、2,191 个时刻的十二关节对照。腰段侧弯和骨盆俯仰曲线取自 117 份离线序列中有连续姿态和刃侧标注的候选弯。SMPL-H 提供离线参照，动力链示意中的负荷与注视方向没有独立实测。

直接打开 `index.html` 可离线阅读，图表、Three.js 和十段短回放均已内嵌。在网站上遇到内嵌视频解码错误时，播放器会改用同目录下的 `media/libXXXXX.mp4`，并按原片时间偏移与网格对齐。下载备用视频时请保留 `media/` 目录名。

GitHub Pages 从 `main` 分支的根目录发布，`.nojekyll` 保留静态文件。网页支持拖动模型、用左右方向键旋转和逐帧回放。
