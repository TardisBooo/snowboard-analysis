# 《从 266 万帧（SMPL-H + HMR）滑雪录像中了解滑雪》

从 1,826 段雪道原片、921 个完整弯道到高精度三维人体姿态，读懂单板刻滑的身体力学。[阅读交互文章](https://tardisbooo.github.io/snowboard-analysis/)

从同一个后刃弯的四帧开始，沿靴、膝和骨盆读一个完整弯。六章依次讲四相位动力链、屈膝与节奏的重复性、三种典型滑法、前后刃的折髋、站姿与前后腿，以及半径与倾角。散点图每点对应一段实际滑行。人体热图用颜色标出双膝与胫骨、骨盆与下腰，角度读数列在图下。

三维实验室收录十段从原片裁出的高清窗口。可以转动 HMR 网格、切换观察部位，用进度条或逐帧按钮在同一时刻对照原片。六章、图表、三维模型和高清短片都内嵌在 `index.html` 中，下载后可离线打开。线上播放器遇到解码错误时会按原片时间切换到 `media/` 内的轻量备用片。
